How this actually works

  • Nothing is uploaded. Reel runs a full copy of FFmpeg compiled to WebAssembly, right in this browser tab, so your video and the extracted audio never touch a server.
  • The first extraction downloads the audio engine (about 25 MB) and keeps it in memory for the rest of your session.
  • Direct video links work if the host allows cross-origin requests. Streaming platforms like YouTube generally block this on purpose, so paste a file link rather than a watch page.
  • Very long or very high-resolution videos take longer and use more memory, since everything runs on your device instead of a server.
Runs entirely client-side using ffmpeg.wasm. Your video is never uploaded anywhere.
